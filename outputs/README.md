# Generated outputs

Model outputs are written below this directory and ignored by Git because a full run produces many large raster and NetCDF files.

Expected products include:

- NOAA station catalogs and station weather CSV files
- cached nClimGrid-Daily and gridMET files
- phase-specific weather and ARID rasters
- annual relative-yield and relative-yield-loss rasters
- bias-correction diagnostics
- ENSO composites
- manuscript figures and summary tables

For a public archival release, store large reproducibility products in a versioned research-data repository and link its DOI from the main README rather than committing the binaries to Git.
